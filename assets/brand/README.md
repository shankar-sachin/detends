# The détends mark

Drop the logo here as `mark.svg` (preferred) or `mark.png`.

Until then the boot sequence renders a typographic placeholder — the wordmark
set in Inter at display weight — so the timing and choreography can be built
and judged now, with the real mark a drop-in replacement.

**What the boot sequence wants** (§20: "Boot should be visually minimal"):

- A single flat colour, so it can be tinted for light and dark. A full-colour
  mark would be the one saturated thing in a near-monochrome system.
- Generous internal margin; the mark sits alone on black and nothing crowds it.
- SVG at any size, or PNG at 1024px or more with transparency.

The sequence is deliberately bare: black, the mark fades up, a beat, then the
shell. No progress bar, no version string, no status text unless something has
actually gone wrong and needs a person.
